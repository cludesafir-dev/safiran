# سایت دکتر جواد فروغی | مؤسسه سفیران

سایت یک‌صفحه‌ای، فارسی، راست‌چین و سازگار با موبایل. ساخته‌شده در ۲۰۲۶-۱۰-۲۵.

## اجرا روی کامپیوتر خودتان
```
cd D:\videos\website
python -m http.server 8765 --bind 127.0.0.1
```
بعد در مرورگر باز کنید: http://127.0.0.1:8765

## فایل‌ها
- `index.html` — همه‌ی متن‌های سایت (معرفی، خدمات، ویدیوها، سؤال‌های رایج، فرم)
- `style.css` — رنگ‌ها و ظاهر (تیره و طلایی)
- `main.js` — منوی موبایل و فرم ثبت‌نام
- `img/` — عکس دکتر، لوگو و عکس ویدیوها · `fonts/` — فونت وزیرمتن (روی خود سایت، بدون نیاز به گوگل)

## فرم ثبت‌نام
فعلاً روی موبایل، فرم یک پیامک آماده به 09150900177 باز می‌کند.
برای ذخیره‌ی خودکار درخواست‌ها: یک پروژه‌ی Supabase با جدول `signups`
(ستون‌ها: name, phone, service, mode, note) و RLS فقط برای insert بسازید
و `supabaseUrl` و `supabaseKey` را در بالای `main.js` پر کنید.

## چیزهایی که باید امیرحسین بازبینی کند
- متن بخش «معرفی» و توضیح خدمات
- جواب‌های «سؤال‌های رایج» (هزینه، زمان، آدرس)
- هنوز منتشر نشده است؛ انتشار فقط با تأیید امیرحسین (پیشنهاد: GitHub Pages)
